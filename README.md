# Nepal Housing Dataset – Data Audit and Exploration

## Project Overview

This project explores a Nepal Housing Dataset to evaluate its quality before performing data analysis and visualization. The project focuses on identifying data quality issues, cleaning the dataset, generating visualizations, and evaluating whether the dataset is reliable for decision-making.

---

## Objectives

- Perform an initial data audit.
- Identify missing values and duplicate records.
- Detect data quality issues.
- Analyze housing prices.
- Create meaningful visualizations.
- Evaluate the reliability of the dataset.

---

## Dataset

Dataset Name: Nepali Housing Price Dataset (nepalhousing.csv)

The dataset contains housing information such as:

- Property Title
- Address
- City
- Price
- Bedrooms
- Bathrooms
- Parking
- Floors
- Area
- Road Information
- Amenities
